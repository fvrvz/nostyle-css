# Typography

NoStyle provides a practical type scale from `.text-xs` to `.text-5xl`, font weight utilities, and semantic colour classes.

```html
<h1 class="text-3xl font-bold tracking-tight">Heading</h1>
<p class="text-muted text-sm">Subtitle text</p>
```
