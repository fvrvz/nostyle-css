# Buttons

NoStyle ships button variants with consistent sizing and subtle hover animation.

Apply `.btn` as the base, then add a modifier like `.btn-primary`, `.btn-secondary`, `.btn-success`, `.btn-warning`, or `.btn-danger`.

```html
<button class="btn btn-primary">Save Changes</button>
<button class="btn btn-secondary">Cancel</button>
```
